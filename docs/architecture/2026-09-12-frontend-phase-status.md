## 明确未完成

| 阶段 | 原因 | 进入条件 |
| --- | --- | --- |
| 游客绑定写入口 | 已接入 Go `/api/auth/bind` 合同、游客用户中心表单、服务端 verifier 边界、严格本地 HMAC verifier 和绑定后 `/me` 刷新 | 真实 OAuth/短信 verifier、会话续期和真实回调仍属于外部授权验收 |
| 资料与安全设置 | 已接入昵称更新、修改密码、退出所有设备；敏感字段只由 Go 服务端处理，密码修改后撤销 Go 会话 | 密码找回/多因素认证未纳入本次范围，需另立合同 |
| 发现、邀请、社交 | 本次用户端范围不包含 | 另行冻结领域合同和权限模型 |
| 反馈公共入口 | 已接入认证后的 Go `/api/feedback` 提交表单，并保留未登录跳转登录 | 真实客服投递、邮件通知和管理后台查看不在本次用户端范围 |
| SSR/SEO 预渲染 | 构建阶段已生成 FAQ、隐私、条款、内容政策四个公共页的静态 HTML；登录和创作页仍保持 SPA，避免把会话数据带入静态产物 | 若需要真正服务端渲染动态页，需另行确定 SSR 部署入口和运行时边界 |
| 旧工具归并/下线 | Animate 已停止入口和新任务；其它非 T2I/I2I/I2V 工具按本次产品范围不迁移 | 若未来恢复其它产品能力，需单独冻结合同，不得混入本次基础能力 |
| 真实支付/生成中台联调 | 当前明确禁止连接生产和真实外部依赖 | 单独授权并完成灰度、回滚与对账验收 |

## 约束

- Animate 不迁移，不恢复入口，不创建任务。
- 前端不读取或推断余额、VIP、每日额度；门禁、预扣、冲正和审核没收由 Go 决定。
- 不修改旧 Node/JS 项目，不接回旧钱包，不把外部中台地址暴露给浏览器。
