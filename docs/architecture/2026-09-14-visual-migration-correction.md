# 用户端视觉迁移校正记录

## 结论

新前端尚未完整还原旧用户端。接口测试、构建通过、复制静态文件不能替代整页迁移验收。
本轮只修改 `ai-frontend-service`，旧前端和 Node 后端保持只读，不连接生产或真实中台。

## 已核实的根因

| 项目 | 源码或运行证据 | 结论 |
| --- | --- | --- |
| 首页 | 旧 `frontend/src/app/AppRoutes.tsx` 的 `HomeGate` 已登录后进入 `/video`；新 `StudioHomePage` 只有说明文字 | 不是首页等价迁移 |
| 模板列表 | 旧 `VideoPresetsMainContent` 使用 `PresetGrid`；新两个创作页仅使用 select | 接口有数据也不会显示封面 |
| 视频封面 | 新 `src/api/media.ts` 原先仅保留图片模板 coverUrl | 视频封面会在解析时丢失 |
| 静态资源 | 上轮复制到 `/legacy/`，但本地图片目录仍返回 `/cling-ai-icon.png` | 文件存在不代表接口引用路径可用 |
| 运行地址 | 5176 上 Vite 的 cwd 是新项目；本地配置仍把 API 指向 5174 | 不是「与本机网络隔离」，而是配置不一致 |
| 本地模板数据 | 5176 的视频目录返回 11 个 `local-video-5-…` 测试项，没有 coverUrl；图片目录返回本地换装测试项和品牌图标 | 真实模板封面尚未导入，不能用任意静态图片补齐 |
| 全站背景 | 上轮把充值背景图用于整个应用；旧 `critical.css` 使用主站主题和内容框 | 不符合旧页面职责和视觉 |
| 反馈路由 | 外层 `/feedback` 无条件跳登录，遮挡内层已登录表单 | 不能依据孤立页面测试声称整页可用 |

## 本轮修复

- `src/features/templates/TemplatePicker.tsx`：公共封面网格，原生 radio 选择、select 同步；选模板不触发上传或创建。
- `src/api/media.ts`：保留视频封面字段并校验类型，继续过滤模型和技术配方。
- 缺少或加载失败的封面明确显示缺图状态，不混用其它模板图片。
- `src/styles/brand.css`：从旧 `critical.css` 提取主站令牌、字体链、560px 内容框和 80px 侧栏尺寸。
- `src/features/shell`：桌面侧栏、移动底栏、当前页选中态和 Lucide 图标；去掉全站充值背景。
- `src/app/router.tsx`：Go 会话恢复后，已登录首页进入视频创作；反馈路由先恢复会话再判断访问。
- `.env.local`：本地 API 基地址对齐到 5176，Go 上游仍为原有本地 18002。

管理后台和 Animate 继续排除。其它入口不在本轮擅自宣告废弃。
真实供应商授权与本地视觉迁移是不同阶段，前者未授权不阻止后者做代码与本地验证。

## 验证标准

回归测试已先复现封面字段丢失、页面没有封面选择、已登录首页不跳转以及反馈路由遮挡。
交付时分别报告测试结果、实际浏览器截图范围和仍缺失的模板数据。
不把本地品牌图标的成功加载表述成旧业务封面的迁移完成。

## 本轮验证结果（2026-09-14）

- 在新项目真实目录运行 `npm test`：19 个测试文件、150 项测试通过。
- `npm run verify:go-only` 和 `npm run build` 通过，后者包括 5 个公共页预渲染。
- 浏览器检查模板编辑页的 390 × 844 和 1440 × 1000 布局：移动底栏、桌面侧栏可见，桌面导航文字不再换行，桌面无横向溢出。
- `/legacy/cling-ai-icon.png` 实际解码成功，仅证明本地测试目录的品牌图片可加载，不代表真实模板封面迁移完成。
- 视频页实际显示 11 个本地测试模板，均无封面，没有用其它图片替代。
- 独立审查发现壳外链接对比度不足。浏览器先复现登录页链接为 2.13:1，补全局链接颜色后复测为 8.84:1。
- 未执行真实中台生成、支付、OAuth 或已登录反馈表单的浏览器提交。认证路由自动化测试不替代真实业务验收。

代码检查、浏览器观察和未完成范围分别记录；上述结果不能证明整个用户端迁移完成。
