# 模板创作详情迁移交接

## 本批范围

延续旧版模板详情交互，将新前端已有的图片编辑、视频创作字段移入详情弹层。只修改 `ai-frontend-service`，不改旧 Node 项目、Go 接口、数据库和生产环境。

- `TemplateSheet` 统一模态、焦点和页面滚动生命周期，不包含业务请求。
- `TemplateCreationDialog` 负责封面、可滚动表单和固定提交区；输入、上传、提交和轮询仍由页面及原有 hooks 管理。
- 选择模板、预览封面、选择文件和关闭弹层均不创建任务。关闭后再次打开保留原生文件输入、已选文件及描述。
- 已选模板可再次点击打开详情；提交期间保留防重入控制。
- 提交时记录模板归属。切换到模板 B 后，模板 A 的异步结果在页面展示，不归入 B，也不取消 A 的轮询。
- 保持现有 Go 请求字段、服务端门禁、预扣和审核语义。未新增任何伪造的 VIP、音频或多图控件。
