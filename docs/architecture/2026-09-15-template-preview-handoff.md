# 模板封面预览接续记录

日期：2026-09-15。接续同目录 `2026-09-15-frontend-media-handoff.md`。

## 本轮已完成

- 新前端 `TemplatePicker` 增加独立预览按钮，不嵌入选择 label。打开、关闭预览不修改选择，点击「使用模板」才确认选择；不上传、不创建任务。
- `TemplatePreviewDialog` 只负责封面展示。沿用旧 `TemplateDetailSheet` 的暗色遮罩、底部面板和标题关闭区，保留当前新前端 560px 内容框。
- 使用原生 `dialog.showModal()` 隔离背景交互和约束键盘焦点；支持 Esc、关闭按钮、遮罩关闭。关闭恢复原滚动设置和仍存在的入口焦点，拖动图片至遮罩不误关。
- 缺封面不打开预览；加载失败不混用其它模板图片。目录加载、失败、禁用或删除当前模板时撤下旧预览，恢复目录不自动重开。
- `template-media.ts` 统一列表、弹层的封面路径解析，仅重映射已核实的品牌图标地址。未修改 API 字段、Go 后端、旧项目、依赖或环境配置。
